# Требования — 2026-10-26-lager-filter

Источник: бриф пользователя от 2026-10-26. Статусы ведутся в `state.json` (`pilot.py req list`); этот файл — читаемая версия
с контекстом. Нумерация `R-n` совпадает со `state.json` и не переиспользуется после удаления.
`pilot.py check` ищет здесь строку таблицы `| R-n |` для каждого требования — заполняй таблицу, а не только state.

## Бриф (как получен)

> Нужен фильтр по складу в списке заказов. Сейчас диспетчер видит все заказы всех складов и теряет время.
> Фильтр должен запоминаться — если я переслал ссылку коллеге, он должен увидеть тот же склад.
> Фильтр должен быть доступен только тем, у кого есть право читать склады; остальные видят список как сейчас.

## Требования

| № | Требование | Вид | Источник | Открытые вопросы |
